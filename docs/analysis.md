# 分析輸出（`job_summaries`）

由 `src/pipeline/analysis.py` 產生。**每一項都有兩版**：`all`（真實 + mock）與 `real`（僅 `source='real'`）。沒有 mock 的任務兩版相同。

| 欄位 | 結構 |
|---|---|
| `metrics.{all,real}` | 篇數、平均/中位數（讚、回覆、轉發、引用、觀看、字數）、平均互動率、星期 × 時段分布（篇數與平均互動率）、文長與互動關係（分箱 + Spearman）、關鍵字（jieba，依「含該詞的貼文數」）、hashtag、貼文類型分布 |
| `top_posts.{all,real}` | 互動率前 5 名 |
| `group_analysis.{all,real}` | 分組規則、各組篇數、每篇貼文的組別（`assignments`）、每組 3–5 篇代表貼文，以及用同一套方法（關鍵字、類型、文長、提問/晚間/連結比例）對代表貼文做的比較 |
| `insights.{all,real}` | 三項假設檢定（提問句→回覆率、晚間→按讚率、含連結→互動率）+ 樣本數提醒 + 最佳時段 |
| `group_analysis.real.writing_guide` | 每組的寫作清單：只含「前後期一致」的特徵（見下方「寫作清單」）；真實貼文 < 20 篇時 `available: false`。只有 `real` 版會產生 |
| `llm_advice` | AI 建議的快取（JSON 字串，依「目標＋模型」存放）；改版前的純文字仍可顯示（見下方「AI 建議」） |

## 寫作清單（`writing_guide`，不需要 migration）

每組綁一個行銷目標：共鳴型 → 擴大觸及、建立好感；討論型 → 帶動討論、收集意見；低迷型 → 要避開或改寫的寫法。

對每一組比較「該組貼文 vs 其他已分組貼文」的 4 個特徵：字數（中位數）、提問句占比、含連結占比、晚間（18:00–23:59）占比，記錄方向（該組較高／較低）與篇數。**只有通過穩定度檢查的特徵才會存下來、顯示、交給 AI**：

1. 分組只用全部貼文算一次，不在前後兩半各算一次
2. 依 `posted_at` 把真實貼文切成前、後兩半
3. 該特徵在兩半的方向相同（不是「相等」），兩半中該組都至少 3 篇，而且**兩半的差距都達最小門檻**：字數中位數相差至少 20%（相對於其他貼文的值）、占比類（提問句／含連結／晚間）至少差 10 個百分點；全部貼文的方向也要一致
4. 真實貼文 < 20 篇（兩半各 < 10 篇）時不做篩選，`available: false`（介面顯示「樣本太少，無法列出寫作清單」）

不穩定的特徵只記數量（`n_unstable`），不記內容。`rewrite_example` 是選配：挑最典型的低迷型貼文，列出它和討論型／共鳴型穩定特徵的差異（不使用 AI）。

## AI 建議（`llm_advice`）

每筆建議帶 `basis`（`p<prompt 版本號>|目標組與低迷型的穩定特徵`）；寫作清單重新分析、或 prompt 改過（`PROMPT_VERSION` 加 1，測試會強制）後指紋不同，舊建議在畫面上會被隱藏，需重新產生。

`{"version": 2, "legacy_text": 舊版純文字或 null, "entries": {"<目標>|<模型>": {goal, model, generated_at, n_posts, advice: {goal, summary, actions: [{do, why, test}] (2–4), avoid}}}}`。送給 Gemini 的只有：目標、該目標對應組別的穩定特徵與篇數、代表貼文特徵、低迷型穩定特徵。該組沒有穩定特徵時不產生建議。

## 定義

- 互動率 = (讚 + 回覆 + 轉發 + 引用) ÷ 觀看；按讚率 = 讚 ÷ 觀看；回覆率 = 回覆 ÷ 觀看
- 觀看數 ≥ 1 萬時 Threads 只顯示到千位（`views_rounded = true`），比率有約 ±5% 以內的誤差
- 晚間 = 台北時間 18:00–23:59；提問句 = 文字含 `？` 或 `?`（網址內的不算）

## 分組（PRD）

1. 觀看 < 該帳號觀看中位數的 20% → **未分組**（比率不可靠），也不參與百分位計算
2. 其餘貼文計算按讚率與回覆率在帳號內的百分位：`(比它小的篇數 + 0.5 × 相等的篇數) ÷ n`
3. **低迷型**：兩者 < 0.5；**討論型**：回覆百分位 ≥ 0.5 且 ≥ 按讚百分位；**共鳴型**：按讚百分位 ≥ 0.5 且 > 回覆百分位
4. 代表貼文：該組「最典型」的 3–5 篇（討論型取回覆百分位最高、共鳴型取按讚百分位最高、低迷型取兩者之和最低；組內不足 5 篇則全取）

`posts.group` 存的是 `all` 版的組別；`real` 版的分組在 `group_analysis.real.assignments`。

## 已知限制

- 真實貼文只有 5–8 篇，百分位與分組在這種樣本下很粗略（例如 7 篇就會有 2–3 篇各組）。
- 檢定用 permutation test（5,000 次，固定種子）；樣本少時 p 值不穩定，`insights` 在 n < 10 時會加註「僅供參考」。
- 關鍵字用 jieba 預設詞典，品牌名/新詞可能被切碎。
